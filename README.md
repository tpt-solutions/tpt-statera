# tpt-statera

> **Status: Phase 1 scope, with Phase 2 code in progress.** The §2 guarantees are **target architecture**
> until the host integration and cross-process concurrency control are built and verified. What exists:
> the single-transfer validator `validate_transfer`, its linear-core proofs, a Floor-only rounding
> policy, and an in-process ledger. It does not deliver host-level enforcement, cross-process atomicity,
> or a completed compliance mapping. See [THREAT_MODEL.md](THREAT_MODEL.md) before citing any claim.

`tpt-statera` is a pure-Rust, domain-agnostic engine for validating financial state transitions and
enforcing economic invariants. It treats each balance update, transfer, or fee calculation as a
conservation-of-value problem, and aims to back that with machine-checked proofs (via `tpt-telos`)
and explicit dust accounting. It is intended as a verification layer for DeFi, payments, tokenomics,
and supply-chain settlement.

## What is in the repository today

| Path | Contents | Status |
| :--- | :--- | :--- |
| `crates/tpt-statera-core` | `validate_transfer`, linear vesting, 10-party atomic netting, fixtures | Implemented, tested. `no_std`, zero dependencies |
| `crates/tpt-statera-policy` | Floor-only rounding policy with mandatory dust destinations | Implemented, tested. `Ceiling` and `HalfEven` rejected by design (AD-4) |
| `crates/tpt-statera-runtime` | In-process `Ledger::submit`, serialized per account; worked examples | Implemented, tested. Not a host integration (AD-7, AD-8) |
| `crates/tpt-statera-proof` | Certificate caveat constant | Stub. The certificate itself is generated by `scripts/` |
| `proofs/` | `tpt-telos` models, negative controls, certificate, transcripts | Linear models verify under both solvers. Nonlinear Floor and vesting models verify under `--solver z3`; see [proofs/README.md](proofs/README.md) |
| `bench/` | FM-elimination latency harness and results; reference hardware record | Gate passes on the frozen reference host, for the netting shape |
| `docs/` | Architecture decisions, control matrix, evidence pack, walkthrough, checklists, audit drafts | See `docs/ARCHITECTURE.md` first |
| `spec.txt` | Design specification (source of truth) | Draft v1, with one revision row added |
| `todo.md` | Master task checklist | In progress |

Total: 48 Rust tests across the workspace, all passing in debug and release.

## Try it

```sh
cargo test --workspace
cargo run -p tpt-statera-runtime --example payments
cargo run -p tpt-statera-runtime --example reference_settlement -- out
cargo clippy --workspace --all-targets -- -D warnings
cargo doc --workspace --no-deps
```

Proofs require a `tpt-telos` build (`cargo build --release -p tpt-telos` in the sibling TPT repo):

```sh
telos verify --solver z3 proofs/transfer_validator_full.telos
telos verify proofs/composition_two_transfers.telos
telos verify proofs/netting_10party.telos
telos verify --solver z3 proofs/floor_fee_exact.telos   # nonlinear: needs the z3 build
python scripts/generate_certificate.py --telos path/to/telos
```
