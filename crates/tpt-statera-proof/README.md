# tpt-statera-proof

Proof-certificate assembly for `tpt-statera`.

> **Status: Stub.** The certificate schema and the first-draft certificate are not implemented in this
> crate. It currently exports only the scope caveat that every certificate must carry (spec §7).

## What exists

- The certificate scope caveat constant.

## Where the certificate comes from

The first-draft Proof Certificate (`proofs/certificate.json`, illustrative) is generated by
`scripts/generate_certificate.py` from `tpt-telos` models under `proofs/`. See
[../../proofs/README.md](../../proofs/README.md) for the models and solver requirements, and
`docs/CERTIFICATE_SCHEMA.md` for the schema.

## Testing

```sh
cargo test -p tpt-statera-proof
```
